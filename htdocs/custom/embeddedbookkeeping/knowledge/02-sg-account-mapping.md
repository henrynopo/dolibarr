# 新加坡公司常见业务 → 科目映射惯例

> 已核对日期：2026-10-09。以下分录为**通用复式记账惯例**，不是法定科目表，
> 税率 9% 与抵扣规则已对照 IRAS 核对（见 `03-iras-gst.md`）。

> **重要**：本表是**通用惯例**，不是法定科目表。实际记账必须以上面提供的
> 【本公司会计科目表】里真实存在的编号为准；本表只有在该编号不存在时才作参考。
> 若公司沿用法国 PCG 编号（4000 客户 / 4000 供应商、6000 收入、6xxxx 费用、
> 2xxxx 资产/负债），下表的口径是相同的。

## 客户发票（开票给客户，收到钱之前不记账）
标准复式记账法（accrual）：
```
借 应收帐款（客户）        含税金额
    贷 销售收入            不含税金额
    贷 销项 GST 9%        税额
```
收到客户付款：
```
借 银行                   收款金额
    贷 应收帐款            收款金额
```
未收款前不记银行存款（避免虚增现金）。

## 供应商发票（收到供应商发票）
```
借 费用/存货（不含税）      不含税金额
借 进项 GST 9%             税额（可抵扣时）
    贷 应付帐款（供应商）   含税金额
```
**进项 GST 只有在以下情况才可抵扣**：该供应商已注册 GST（有 GST 注册号）、
公司自己已注册 GST、并且发票上有公司抬头与 GST 号。
不可抵扣的进项（例如交通、酒店、餐饮娱乐、个人消费）要**直接计入费用，不得进进项税科目**。

## 定金发票 / 预收款
收到定金（未履约）**不确认收入**：
```
借 银行                   定金金额
    贷 合同负债 / 预收帐款   定金金额
```
履约开票时再确认收入并冲销预收。

## 贷记单（credit note / 红字发票）
```
借 销售收入               红字金额
借 销项 GST               红字税额
    贷 应收帐款            红字含税额
```

## 费用报销单
```
借 费用科目（按费用性质逐行）
借 进项 GST               可抵扣部分
借 不可抵扣项目            不可抵扣部分（餐饮/交通等）
    贷 员工应付 / 银行      实际支付或待付金额
```
「员工应付」是过渡科目，实际付款时再借 银行 冲平。

## 银行与现金
- 银行手续费：借 银行手续费费用 / 贷 银行
- 银行汇兑损益：收付款金额与账面金额不一致的部分进 汇兑损益
- 现金日记账仅用于确实有现金收付的小额业务

## 预付费用（年费、租金、保险）
付款时先挂预付，按月摊销：
```
付款时：借 预付费用   贷 银行
摊销时：借 费用      贷 预付费用
```

## 固定资产
- 购置：借 固定资产（成本+相关直接费用）/ 贷 应付或银行
- 折旧：借 折旧费用 / 贷 累计折旧
- 处置：借 银行 + 累计折旧 / 贷 固定资产 + 处置损益
- 准则依据：**FRS 16**（不动产、厂房及设备）。
  - 应计折旧额 = 成本 − 残值，按**预计使用年限**分摊；折旧方法须反映消耗方式
    （直线法最常用），**须反映消耗而非仅仅使用**。
  - 残值与使用年限是估计，**至少每个财年末复核一次**，变动按估计变更**未来适用**。
  - **土地通常不计提折旧**；建筑物若有重大土地成分，应单独拆分。
  - 已提足折旧但仍在使用的资产，仍按成本减累计折旧列示，**不再计提**。
  - 单项成本低于本公司资本化门槛的直接费用化（ACRA 不设统一金额，由公司自定政策）。

## 工资与 CPF（新加坡）
- 计提：借 薪资费用 / 贷 应付工资；借 CPF 雇主承担部分 / 贷 CPF 应付
- 发放：借 应付工资 / 贷 银行
- 本公司的工资数据由 HR 模块同步，分录在工资模块生成，记账模块只做核对

## 对账与结账
- 银行对账差异在结账前必须清零
- 期间结账前：核对 借贷平衡、往来科目余额与第三方对账一致、存货与成本一致
